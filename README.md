# 延安退耕还林（1999—2025）数据分析成果

延安市 1999—2025 年退耕还林的土地利用变化、植被变化与归因分析成果。
数据源：CLCD 土地利用、MODIS NDVI、TerraClimate 气候、Copernicus DEM、WorldPop、OSM、HWSD 土壤。

## 目录

```
01_表/   面积、转移矩阵、分坡度、分县、增绿分解、模型精度、贡献统计
02_图/   模型验证、变量重要性、退耕贡献、热点分析、分坡度分县
04_脚本/ Python 后处理脚本（栅格化、分区统计、分块验证、热点、转移矩阵、出图）
PPT数据替换表.xlsx   汇报 PPT 逐页数据替换清单
数据核对报告.txt     一致性检查与已知问题
```

## 关键结果

- 30 m 遥感退耕（耕地→林/草）**2,648.7 km²**，占 1999 年耕地 **43.1%**
- 耕地 1999→2025 净减 **1,458.3 km²**（−23.7%），2010 年后回升 405.2 km²
- 林地净增 **3,151.1 km²**，草地净减 1,817.4 km²
- 随机森林（1000 棵、深度 12）：训练 R² **0.90**、验证 R² **0.85**
- 变量重要性：FOR99 44.1%、PREC 16.0%、GFG 12.7%
- 反事实贡献：全市 **+0.0037**，占观测增绿 **1.90%**；退耕集中区 **3.48%**
- Getis-Ord Gi*：热点 11,468 个 1 km 网格，集中在子长、志丹、吴起、延川

## 说明

1. 模型在 ArcGIS Pro 3.7 的 GeoAnalytics 森林工具中训练，实际算法为**随机森林**，非 XGBoost（该版本无梯度提升工具）。
2. 空间分块交叉验证由 Python 等价程序复现（`04_脚本/run_block.py`），非 ArcGIS 输出。
3. 栅格数据（250 m 贡献面、预测面等）因体积与数据许可未包含在本仓库，仅保留派生表格与图件。
4. 尚未完成：SHAP、地理探测器、9.12 NDVI 组合效应、PLUS 校准精度。
