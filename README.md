# 延安退耕还林（1999—2025）数据分析成果

延安市 1999—2025 年退耕还林的土地利用变化、植被变化与归因分析成果。
数据源：CLCD 土地利用、MODIS NDVI、TerraClimate 气候、CRU TS v4.10 降尺度气候、Copernicus DEM、WorldPop、OSM、HWSD 土壤。

> **2026-11-09 更新**：完成 XGBoost（梯度提升）重做，见 `05_XGBoost重做/`。
> 此前基于随机森林的结果保留在 `01_表`、`02_图` 中作为对照，两者不可混用。

## 关键结果（XGBoost 重做，最新）

模型在 ArcGIS Pro 3.7 空间统计工具箱「基于森林和增强的分类与回归」（`Forest_stats`）中训练，
模型类型=梯度提升，随机种子 42。

**模型 A 退耕分类**（trainA 24,752 / testA 24,953，10 个变量，未含土壤）：

- 训练 F1 0.87、准确率 0.87；验证 F1 0.79、准确率 0.79、MCC 0.57
- 检验集 AUC **0.873**；仅坡度模型 AUC 0.807
- 重要性：坡度 34%、PREC90 19%、DEM 14%、TMP90 8%、人口 6%
- 交叉验证准确率：随机5折 0.788、空间5折 0.747、空间10折 0.754、坡度空间5折 0.706

**模型 B NDVI 回归**（9,939 点，13 个变量）：

- 训练 R² 0.946、验证 R² **0.853**
- 重要性：FOR99 32.2%、PREC 26.3%、TMP 11.9%、SLOPE 9.8%、**GFG 1.6%**
- 交叉验证 R²：随机5折 **0.836**；空间5折 0.545、10折 0.489、20折 0.441
- 反事实：pred_real 0.19356、pred_cf 0.19086，贡献 **+0.0027（占观测 1.40%）**

## 关键结果（随机森林，早期版本，仅作对照）

- 30 m 遥感退耕（耕地→林/草）**2,648.7 km²**，占 1999 年耕地 **43.1%**
- 耕地 1999→2025 净减 **1,458.3 km²**（−23.7%），2010 年后回升 405.2 km²
- 林地净增 **3,151.1 km²**，草地净减 1,817.4 km²
- 随机森林（1000 棵、深度 12）：训练 R² 0.90、验证 R² 0.85
- 变量重要性：FOR99 44.1%、PREC 16.0%、GFG 12.7%
- 反事实贡献：全市 +0.0037，占观测增绿 1.90%
- Getis-Ord Gi*：热点 11,468 个 1 km 网格，集中在子长、志丹、吴起、延川

## 说明

1. ArcGIS Pro 3.7 的空间统计工具 `Forest_stats` **支持梯度提升**（模型类型可选「梯度提升」）；
   GeoAnalytics 的 `Forest_geoanalytics` 只有随机森林。两套结果分别对应 `05_XGBoost重做/` 与 `01_表`。
2. 模型 A 未纳入土壤类型（SOIL 类别过多，按要求剔除），实际 10 个变量。
3. 模型 B 的 BUILDNEW 因变化性不足（4% 非零）被工具拒绝，实际 13 个变量。
4. 模型 A 的距离变量使用已有 30 m 距离栅格，与「距离要素」等价但快一个量级。
5. 栅格数据（250 m 贡献面、预测面等）因体积与数据许可未包含在本仓库，仅保留派生表格与图件。
6. 尚未完成：SHAP、地理探测器、9.12 NDVI 组合效应、PLUS 校准精度。
